# ClockMath (clockmathtools.com)

Free time calculators. Every change saved here goes live on clockmathtools.com in about a minute.

## How to make a small text edit

1. Open the **public** folder and click the page you want to change (see list below).
2. Click the ✏️ pencil icon (top right of the file).
3. Press **Ctrl + F** to find the words you want to change, and edit only the words between the `>` and `<` marks.
4. Click **Commit changes…**, then **Commit changes** again.
5. Wait about a minute, then refresh the page on clockmathtools.com.

Tip: if you make a mistake, open the file's **History** to see or undo earlier versions.

## Safe to change

- Headings, paragraphs, FAQ questions and answers, link text.

## Ask Claude first

- Anything inside `<script>` tags (the calculators), styles.css, sitemap.xml, wrangler.jsonc, or adding/removing pages.
